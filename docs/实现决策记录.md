# Awen 实现决策记录(设计偏离与边界确认)

> 2026-09-21。对照《原型设计方案.md》《开发计划.md》逐项确认后的决策记录。
> 性质:承认实现与设计的偏离,锁定决策,避免反复。每条含理由与影响。

## D-R1 撤销/重做走前端 hist,不接引擎 undo.aine(E1-5 偏离)

**决策**:保留前端 hist 数组(语义步:500ms 窗口合并+标点成步+基线入栈),不把
undo.aine 双栈接入编辑链路。

**理由**:撤销必须与 DOM 光标恢复、跨页渲染联动,引擎双栈面向"源码 patch"模型;
接入需要 patch↔DOM 双向同步层,复杂度高于收益。引擎 undo.aine 保留(测试全绿),
作为未来"语义编辑 API"的组成部分。

**影响**:§4.4 合并规则由前端语义步等价实现;跨文件切换时撤销栈重置(文件隔离)。

## D-R2 选区映射(inline_span_map)不接入当前 UI(E2-1 偏离)

**决策**:纸面编辑走"DOM 序列化回写"路径(serializeAll);inline_span.aine 的
选区↔源码区间映射能力保留为引擎 API,不在 WYSIWYG 视图接入。

**理由**:DOM 回写已支撑全部当前编辑场景(粗斜/颜色/表格/作用域回写);
选区映射的价值在"源码视图高亮同步",列为语法视图增强的候选,非必需路径。

**影响**:E2-1 的验收(选区映射正确)由序列化往返一致性测试等价覆盖。

## D-R3 分页一致性:以前端像素实测为准(E3-1/E3-4 决策)

**决策**:分页结果的权威是**前端像素级实测分页**(DOM 真实字体测量);
引擎 page_flow(均匀宽度模型)作为排版算法基线保留。导出/打印以前端 DOM 快照为准。

**理由**:前端 DOM 测量天然获得真实字体宽度(等价达成 E3-1 目标);
导出 HTML 内嵌 DOM 结构,与前端分页天然一致。引擎侧真实字体度量(P3-1)
在浏览器路径下无增量收益,仅在纯 CLI 排版输出时需要。

**影响**:引擎 `core_parse` 返回的 pages 字段仅供参考;页码域(§7.4)在
导出路径不承诺与引擎一致。

## D-R4 增量解析/布局:暂不接入(E3-4/E6)

**决策**:行级增量(lex_incremental)与增量布局(page_flow_incremental)
保留在引擎并维持测试,编辑器暂不接入,继续全量解析+像素重排。

**理由**:当前文档规模(<百页)全量路径 <50ms,增量收益不显著;
接入成本是双向缓存一致性维护。触发条件:单文档 >200 页或交互卡顿实测出现。

## D-R5 多行作用域 @[font/size/color] 引擎侧未支持(已知分歧)

**决策**:预览引擎(ingestNative 之前)支持多行作用域块的解析/渲染/序列化;
Aine 原生解析器暂不识别(按 docset+段落处理)。桌面版通过"引擎分歧"警告暴露。

**影响**:含多行作用域的文档在桌面版打开时块结构来自原生(语义降级);
待规范确认作用域的块级语义后在 parser.aine 补齐。

## D-R6 表格 widths 列宽为编辑器扩展

**决策**:`@[table 名 widths: 30,40,30]` 参数由前端实现(colgroup 渲染+回写),
不进入 Awen 核心规范;native 解析器视 table 开行为不透明行,不冲突。

**影响**:该参数在纯 CLI 排版路径无效果;晋升为规范需先冻结语法。
