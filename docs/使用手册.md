# Awen 文档编辑器 · 使用手册

> 版本 v1.0(2026-09) · 适用平台 Windows 10/11 x64

Awen 是一款"aine 引擎 + 桌面壳"的中文文档编辑器:你在**所见即所得的纸面**上写作,引擎用同一份 **Awen 源码**作为唯一权威。既可像 Word 一样排版写作,也可随时切换到语法视图精确控制。

---

## 1. 安装与启动

1. 运行 `Awen 编辑器_1.0.0_x64-setup.exe`,按向导完成安装。
2. 安装完成后从开始菜单启动 **Awen 编辑器**。
3. 启动后是一个空白文档。`.awen` 文件已关联本程序,双击即可打开。

## 2. 界面总览

```
┌ 标题栏:[文件] 撤销 重做 保存 [文档标签×]           设置 ⚙ 帮助 ?
├ 选项卡:开始 | 插入 | 设计 | 页面 | 引用 | 审阅 | 视图
│         (选中表格/图片时自动出现"表格工具/图片工具")
├ 功能区:当前选项卡的按钮组
├ 文档结构(侧栏,可收起)/ 纸面编辑区 / 语法窗格(分屏时)
└ 状态栏:诊断 · 字数 · 标签 · 位置 · 缩放 · 页数
```

- **文件菜单**:点击标题栏蓝色"文件"按钮——新建/打开/保存/另存为/导入 docx/打印,以及导出为 Markdown / HTML / Word / TXT 和最近文件。
- **多文件**:再打开或新建文档时会新增一个标签;点标签切换,点标签上的 ✕(或中键)关闭。未保存的文档关闭前会确认。双击标签可修改文档名。
- **设置(⚙)**:自动保存开关、编辑标记开关、护眼主题等。

## 3. 写作:显示视图(默认)

纸面就是 A4 页面,直接输入即可,回车分段。常用操作:

| 操作 | 入口 |
|---|---|
| 粗体/斜体/删除线/上下标 | 开始→字体(或 Ctrl+B / Ctrl+I,选中后点按钮) |
| 字体颜色 / 底纹高亮 | 开始→字体,点色块立即应用,点箭头选更多颜色 |
| 清除格式 | 开始→字体 → 橡皮擦按钮 |
| 项目符号 / 编号列表 | 开始→段落 |
| 对齐 / 行距 | 开始→段落 |
| 样式(标题层级) | 开始→样式:正文 / 标题 1~3,或下拉选 4~6 级 |
| 查找替换 | Ctrl+F / Ctrl+H |
| 撤销/重做 | Ctrl+Z / Ctrl+Y(或标题栏按钮) |

带**红点角标**的按钮是规划中的功能,点击会提示;不影响其他功能。

### 3.1 图片

插入→图片,选择本地图片(PNG/JPG/GIF/WebP,≤1MB)后以原始尺寸插入;可在**图片属性面板**(点击图片)调整宽度百分比与对齐。保存 .awen 时图片自动收进文档包,不再依赖原路径。

### 3.2 表格

插入→表格,拖选行列插入。选中单元格后功能区出现**表格工具·布局**:+行/−行/+列/−列。浮动工具栏也会出现表格按钮。

## 4. 语法视图与分屏

视图→语法:同一张 A4 纸的几何,左侧是行号,右侧是 Awen 源码——**这里看到的源码才是文档的本体**。

- 显示视图里的每次编辑都会同步回源码(标点后立即,一般输入约 0.3 秒)。
- 分屏:视图→分屏,两侧滚动按"源码行 ↔ 文档块"锚定联动。
- 左右交换:分屏时对调两侧;拆分/分屏等价。

常用语法速查(完整规范见《Awen 核心规范》):

```text
# 一级标题        ## 二级标题
**粗体**  _斜体_  ~~删除线~~  `行内代码`
@[u]下划线@[/u]   @[color #3366CC]彩色@[/color]
@[font "SimSun"] 这一行的字用宋体        (中文方言:@[字体 宋体])
@[image "照片.png" width 60% align center]
@[table t]
| 列A | 列B |
| --- | --- |
| 1  | 2  |
@[/table]
> 引用          - 无序列表        1. 有序列表
---             @[comment 批注,不进排版]
@[toc depth: 2]                         (插入目录)
@[page A4] @[margin 20mm] @[line-spacing 1.9]   (文档级设置)
```

显示视图中,文档设置行与批注显示为**细色条**(灰=设置、黄=批注),把鼠标悬停可看内容;想编辑它们请切到语法视图。

## 5. .awen 文件包

`.awen` 是单文件容器,内部结构:

| 区 | 内容 |
|---|---|
| User Syntax | Awen 源码,**明文 UTF-8**,唯一权威——用记事本即可打开阅读,Git/AI 可直接处理 |
| Manifest | 版本、文档 ID、资源清单(名称/大小/哈希) |
| Resources | 图片等资源(按内容哈希命名,自动去重) |
| Canonical | (预留)编译缓存,可丢弃,损坏后自动重建 |

- 保存采用**原子提交**(先写临时文件再替换),中途断电不会损坏原文档。
- 图片保存时自动收进包内,文档拷贝到任何电脑都不丢图。
- 旧版纯文本 .awen / .txt / .md 依旧可以直接打开。

## 6. 导出与打印

文件→导出为:Markdown / 网页 HTML / Word(.doc)/ 纯文本。打印(Ctrl+P)走系统打印,可另存为 PDF。

## 7. 页面与视图

- 页面选项卡:纸张(A4/Letter/B5/A3/A5)、方向、页边距、行距、首行缩进、段间距——所有设置都写回源码(如 `@[page A4]`),源码即权威。
- 视图选项卡:显示/语法/分屏;专注模式(隐藏一切界面,Esc 退出);导航窗格;编辑标记;缩放(状态栏也可调)。

## 8. 快捷键

| 键 | 功能 |
|---|---|
| Ctrl+N / O / S | 新建 / 打开 / 保存 |
| Ctrl+Z / Y | 撤销 / 重做 |
| Ctrl+B / I / U | 粗体 / 斜体 / 下划线 |
| Ctrl+F / H | 查找 / 替换 |
| Ctrl+P | 打印 |
| Alt+0~6 | 应用正文/1~6 级样式 |
| Ctrl+Shift+. / , | 增大 / 减小字号 |
| Esc | 退出专注模式 / 关闭弹层 |

## 9. 数据安全

- **自动保存**:编辑内容定时快照到本机;意外退出后下次启动自动恢复,并可一键放弃草稿(文件菜单)。
- .awen 保存为原子替换,不会出现"写一半"的损坏文件。
- 资源损坏时打开会明确报错,不会静默丢失。

## 10. 常见问题

- **点"图片"没反应?** 会弹出系统文件选择框,请选择图片文件(≤1MB)。
- **分屏两侧滚动不一致?** 已按"源码行 ↔ 文档块"锚定;因渲染页高与源码行数比例不同,靠近页面边缘时会有少量偏差。
- **带红点的按钮?** 规划中的功能,点击有提示;完整规划见《功能区规划》。
- **在哪里看到纯净源码?** 视图→语法;或用任意文本编辑器打开 .awen,清单之后的内容就是源码。

——Awen,把排版交给引擎,把写作还给你。
