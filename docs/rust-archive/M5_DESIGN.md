## 4. M5-a 技术要点(全量布局)

- **测宽模型**(原型级,统一自 D-2/D-1):全角(CJK 表意/扩展 A、全角标点)= 1.0em;
  ASCII 字母/数字/半角标点/空格 = 0.5em;CJK↔Latin 边界加 0.125em。pt→mm = ×0.352778。
- **断行单元化**:连续 Latin 字母数字 = 不可分词;单个 CJK 字符 = 单元;
  行首禁则字符粘附前一单元、行尾禁则字符粘附后一单元(禁则在断行时满足,§10.3);
  超宽单元硬切兜底。
- **分页流**:遍历 SemNode 树按块流排版;行高 = 字号 × 行距(默认 1.65,§20);
  Comment 不参与渲染(§11.3);图/表占位高度(原型:图 40mm,表按行数)。
  产出:页列表(每页的行位置)+ 节点级 LayoutBox(start_page/end_page/行数)。
- **Layout Resolver(§7.2)**:Label 锚点 → 页码;**收敛循环(§7.4)**:页码表喂回排版,
  迭代至稳定,上限 4 次;正常文档 1 次即收敛。实时路径允许 stale(§7.3)由编辑器层
  决定,布局库只提供单次全量 + 收敛包装。
