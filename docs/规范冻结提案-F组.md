# Awen 规范冻结提案(F 组:页眉页脚/嵌套列表/字符间距/段间距)

> 2026-09-21。目的:为"规范未定义不做"清单给出**候选语法冻结案**,供拍板。
> 状态:**提案**——批准后进入实现排期;未批准前前端/引擎均不实现(不自造规范)。

## F-1 页眉页脚

```user-syntax
@[header text "文档标题"]          ← 页眉文本({page} 为页码占位)
@[header align center]
@[footer text "{page} / {pages}"]
@[footer off]                      ← 关闭
```

- 作用域:文档级,出现即生效,后者覆盖前者
- 渲染:每张纸顶部/底部固定区(高度计入版心,分页重算)
- 引擎影响:page_flow 需感知版心缩减;前端 CSS 定位
- 序列化:原样回写 docset 行

## F-2 嵌套列表

```user-syntax
- 一级项
  - 二级项(两空格缩进)
    - 三级项(四空格)
1. 有序同样支持两空格层级
```

- 规则:行首前导空格数 /2 取整为层级(0-5);层级变化即开新子列表
- 引擎影响:lexer 逐行分类需保留前导空格;parser 列表组递归;**改动集中且可测**
- 渲染:嵌套 ul/ol;margin 随层级

## F-3 字符间距

```user-syntax
@[spacing 0.1em]加宽文字@[/spacing]     ← 行内作用域,复用作用域机制
```

- 渲染:CSS letter-spacing;分页度量在 measureEm 中计入
- 引擎影响:行内扫描新增命令;layout_width 宽度系数 +0.1em/字

## F-4 段间距

```user-syntax
@[para-spacing 0.5em]        ← 文档级,段间距
@[para-spacing off]
```

- 渲染:段落 margin-bottom;像素分页自动计入
- 引擎影响:page_flow 行高模型加段间距项

## 优先级建议

嵌套列表 > 段间距 > 页眉页脚 > 字符间距(按用户价值与实现风险排序;
嵌套列表引擎改动最集中但规格清晰,段间距最小)。
