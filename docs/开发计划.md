## 1. E1:最小可行编辑器(文本级)

**目标**:打开 .awen 文件 → 在文本区域编辑 → 实时看到分页结果和格式标记。

| 项 | 内容 | 依赖 |
|---|---|---|
| E1-1 文件打开/保存 | load_awen / save_awen 接入 | container.aine |
| E1-2 文本编辑区 | 多行文本框;每次变更触发 pipeline_full | pipeline.aine |
| E1-3 大纲导航 | 侧栏显示标题树(heading_tree.aine);点击滚动到对应行 | heading_tree.aine |
| E1-4 状态栏 | 诊断(错误/警告)、字数统计(compute_doc_stats)、光标位置 | validate.aine |
| E1-5 撤销/重做 | Ctrl+Z / Ctrl+Y 接入 undo.aine 双栈 | undo.aine |
| E1-6 分页预览 | 只读面板显示 page_flow 结果(页分隔线 + 每行文本) | page_flow.aine |

验收:打开 corpus/all_syntax.awen → 编辑标题/段落 → 分页预览实时更新 → Ctrl+Z 还原。

## 2. E2:显示编辑(粗斜/属性/表格)

**目标**:从纯文本编辑升级为"所见即所得"。

| 项 | 内容 | 依赖 |
|---|---|---|
| E2-1 选区映射 | inline_span_map:选区 → 源码区间;源码区间 → 显示高亮 | inline_span.aine |
| E2-2 粗斜切换 | Ctrl+B/I/S → toggle_bold/italic/strike → patch → 管线 | inline_edit.aine |
| E2-3 标题级别 | 工具栏 H1-H6 切换 → 修改行首 # 数量 → patch | mapping.aine |
| E2-4 表格编辑 | 点击单元格 → 编辑内容;行列增删 → 表格 patch | parser.aine(TableNode) |
| E2-5 图片属性 | 点击图片 → 属性面板(width/label)→ SetObjectAttr patch | §3.4 |
| E2-6 Label 面板 | 文档 Label 列表;点击跳转;重命名(Label 持久性) | refs.aine |

验收:选中文本 → Ctrl+B → 源码出现 `**`;选区映射正确;P-09 场景可操作。

## 3. E3:排版深化

**目标**:从均匀宽度模型升级为接近印刷的排版质量。

| 项 | 内容 |
|---|---|
| E3-1 字体度量 | 接入真实字体宽度(替换 1em/0.5em 均匀模型);字体子集/回退(§47–53) |
| E3-2 标点挤压集成 | layout_squeezed_width 接入 page_flow 测宽管线(目前独立函数) |
| E3-3 行距/段距可配 | @[line-spacing] / @[margin] 等文档级设置生效 |
| E3-4 增量布局 | page_flow 页输入状态快照 → 编辑只重排受影响页(§42) |

## 4. E4:导出与发布

| 项 | 内容 |
|---|---|
| E4-1 HTML 导出完善 | 语义标签(h1-h6/p/table/strong/em)+ CSS 内联 |
| E4-2 打印布局 | 分页结果 → 打印友好的 HTML/PDF |
| E4-3 .awen 格式完善 | 资源 chunk(图片嵌入);格式版本迁移 |
