版本:v2(2026-09-19 重构)。语言:**Aine(唯一实现线)**。
依据:《Awen文档格式与编译渲染系统.md》(总方案)、《Awen核心机制规范.md》v0.4(冲突时以此为准)。

## 1. 定位

Awen 用 **Aine** 实现——这本身就是 Aine 语言生态的旗舰验证:文档系统是编译管线、
增量计算、排版、持久化的综合性真实负载。

原 Rust 工作区(awen-proto)是开发期引入的验证骨架,已完成其历史使命
(确认了设计可行、§45 性能预算可达、属性测试方法论有效),验证结论沉淀于
`docs/rust-archive/`,实现已移除。**后续所有功能只在 Aine 侧开发。**

## 3. 已定稿的实现决策

| # | 决策 | 结论 |
|---|---|---|
| D-1 | 中西文混排间距 | **⅛ em**(layout_width.aine 为唯一实现;旧 cjk_mixed_spacing_text 的 ¼em 标记函数仅作历史模拟) |
| D-2 | CJK/Latin 分类 | **layout_width.aine 统一实现**(表意/扩展A + CJK 标点区 + 全角形式区;不再用 `> U+7F` 近似) |
| D-3 | 西文断词 | **词边界断行**:连续字母数字为不可分单元;行首禁则字符粘附前单元;行尾开启标点移入下一行(禁则一体化) |
| D-4 | ID 携带 | 编辑局部性复用:变更行之外的节点保持 NodeId(incremental.aine);禁止按内容匹配(§1.3) |
| D-5 | 容器 | .awen v0.4:清单 + 明文 User Syntax(codec=none,§8.6);往返逐字节验证 |

## 5. 待办(按优先级)

1. **增量布局稳定点**(§42):编辑 → span 定位受影响页 → 向前重排 → 页输入状态不变即停;
   分页流(page_flow)已是逐节点推进结构,加"页输入状态快照 + 比对"即可
2. **属性测试驱动器**:确定性 LCG 随机操作(插入/删除/属性/标题改名/Undo)+
   不变量断言(语义等价/ID 不变量/最小修改),作为 401 个确定性测试之外的对抗验收线
3. **事务引擎深化**:语义操作编译为最小 patch + §1.4 ID 规则表(复制新 ID/恢复新 ID)的系统化
4. **Canonical 缓存**(§8):按需——校验=重建,非必需
5. **P-09 表格属性最小修改**:需要行内区间映射后实施
