# Awen 原型设计方案(Aine 主线)

版本:v2(2026-09-19 重构)。语言:**Aine(唯一实现线)**。
依据:《Awen文档格式与编译渲染系统.md》(总方案)、《Awen核心机制规范.md》v0.4(冲突时以此为准)。
历史参考:`docs/rust-archive/`(Rust 验证骨架的结论沉淀,已于 2026-09-19 移除该实现线)。

---

## 1. 定位

Awen 用 **Aine** 实现——这本身就是 Aine 语言生态的旗舰验证:文档系统是编译管线、
增量计算、排版、持久化的综合性真实负载。

原 Rust 工作区(awen-proto)是开发期引入的验证骨架,已完成其历史使命
(确认了设计可行、§45 性能预算可达、属性测试方法论有效),验证结论沉淀于
`docs/rust-archive/`,实现已移除。**后续所有功能只在 Aine 侧开发。**

## 3. 已定稿的实现决策

| # | 决策 | 结论 |
|---|---|---|
| D-1 | 中西文混排间距 | **⅛ em**(layout_width.aine 为唯一实现;旧 cjk_mixed_spacing_text 的 ¼em 标记函数仅作历史模拟) |
| D-2 | CJK/Latin 分类 | **layout_width.aine 统一实现**(表意/扩展A + CJK 标点区 + 全角形式区;不再用 `> U+7F` 近似) |
| D-3 | 西文断词 | **词边界断行**:连续字母数字为不可分单元;行首禁则字符粘附前单元;行尾开启标点移入下一行(禁则一体化) |
| D-4 | ID 携带 | 编辑局部性复用:变更行之外的节点保持 NodeId(incremental.aine);禁止按内容匹配(§1.3) |
| D-5 | 容器 | .awen v0.4:清单 + 明文 User Syntax(codec=none,§8.6);往返逐字节验证 |

## 5. 后续开发计划(三阶段)

> 原则:单实现线(Aine);每阶段以验收器收尾;结构性改动前先 git commit;文档随代码同步。

### P1 正确性防线(验收器先行,规模最小、保护最大)—— P1-1 已完成(2026-09-19,tests_property.aine:4 条对抗性属性)

| 项 | 内容 | 验收 |
|---|---|---|
| P1-1 属性驱动器 | 确定性 LCG 随机操作会话(插入/删除/标题改名/属性/Undo)+ 不变量断言:①语义等价(每步==重解析) ②ID 唯一且消亡不复用 ③最小修改 ④注释存活 ⑤方言不改写 | 5 种子 × 100 步全绿,失败按种子回放 |
| P1-2 增量布局稳定点(§42) | page_flow 页输入状态快照(首节点 ID+纵向偏移)→ 增量重排 → 不变即停 | 尾部编辑复用 >90% 且增量==全量逐行一致 |
| P1-3 事务系统化 | 语义操作统一入口(编译为最小 patch)+ §1.4 ID 规则表 + §4.4 连续输入合并 | 既有测试零回归 + 事务专项测试 |

### P2 编辑器就绪(双视图闭环的最后一公里)

| 项 | 内容 | 解锁 |
|---|---|---|
| P2-1 行内区间 | 行内原子携带源码区间 → 显示选区 ↔ 源码区间映射 | P-09 前置;粗斜切换 |
| P2-2 显示侧编辑 | 粗斜/删除线切换、表格单元格属性最小修改(§9/P-09) | P-09 转绿 |
| P2-3 页码 resolver | §7.2 两级解析;§7.3 实时 stale;§7.4 导出收敛 ≤4 次 | 目录页码 |
| P2-4 Undo/Redo | 双栈 + §4.4 合并(连续同类输入一个单元);逐字节还原 | P-06 转绿 |

### P3 产品化(按需启动)

| 项 | 内容 |
|---|---|
| P3-1 字体度量 | 真实字体宽度接入替换均匀模型;子集/生僻字回退(§47–53) |
